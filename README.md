# 🏥 Hospital de la Felicidad - ¡Feliz Cumpleaños, Dr. Armando! 🎂🩺

Una experiencia web interactiva 3D con temática hospitalaria y médica creada para homenajear a **Armando** en su cumpleaños.

---

## 🌟 Características de la Experiencia

1. **Fachada y Puertas Principales de Urgencias 3D:**
   - Letrero luminoso del hospital con balizas de emergencia.
   - Puertas dobles que se abren con efecto tridimensional al tocar "Ingresar al Hospital".
   - Alerta médica festiva: *"Código Fiesta Activado"*.

2. **Pasillo de Consultorios Médicos 3D:**
   - 5 consultorios temáticos con puertas batientes 3D que se abren al tacto:
     - **Consultorio 101:** *Cardiología de Recuerdos 🫀*
     - **Consultorio 102:** *Traumatología & Risas 🩺*
     - **Consultorio 103:** *Quirófano: Operación Éxito 👨‍⚕️*
     - **Consultorio 104:** *Urgencias de Abrazos 🚑*
     - **Consultorio 105:** *Farmacia de Deseos & Pastel 🎂*
   - Cada consultorio revela una fotografía enmarcada, dedicatoria especial e historia clínica.
   - Opción para ver cada foto en pantalla completa (Lightbox zoom).

3. **Fórmula Médica Oficial (Prescripción de Cumpleaños 📋):**
   - Recetario médico auténtico con tratamiento especial: dosis de pastel, risas ilimitadas y abrazos de familiares y amigos.
   - Botón para guardar o imprimir la receta.

4. **Monitor Cardíaco ECG Interactivo y Efectos de Sonido:**
   - Ritmo cardíaco visual en el encabezado.
   - Sonidos sintetizados nativamente (chimes hospitalarios, beeps médicos y fanfarria festiva) sin depender de archivos externos.
   - Lluvia de confeti festivo con Canvas Confetti.

## 📸 Cómo Reemplazar las Fotos por las Fotos Reales de Armando

Para agregar las fotos reales de Armando:
1. Abre la carpeta `fotos/`.
2. Guarda tus imágenes con los siguientes nombres:
   - `foto1.jpg` (o `.png`) -> Consultorio 101
   - `foto2.jpg` (o `.png`) -> Consultorio 102
   - `foto3.jpg` (o `.png`) -> Consultorio 103
   - `foto4.jpg` (o `.png`) -> Consultorio 104
   - `foto5.jpg` (o `.png`) -> Consultorio 105
3. ¡Listo! La página web detecta automáticamente tus fotos y las mostrará al instante. Si aún no colocas alguna, mostrará la ilustración médica correspondiente.

## 🚀 Cómo Subir a GitHub y Publicar en GitHub Pages

1. Entra a [github.com/new](https://github.com/new) y crea un nuevo repositorio llamado:
   `cumpleanos-armando` (público).
2. Conecta y sube el repositorio con los comandos:
   ```bash
   git remote add origin https://github.com/YonathanBaquero/cumpleanos-armando.git
   git branch -M main
   git push -u origin main
   ```
3. En la configuración de GitHub (`Settings` -> `Pages`), activa GitHub Pages en la rama `main`.
4. Tu enlace público para compartir quedará listo en:
   `https://yonathanbaquero.github.io/cumpleanos-armando/`
